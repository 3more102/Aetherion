Aetherion Mobile

Install this experimental web app

On supported Android browsers, use Install app or Add to Home screen from the browser menu. On iPhone Safari, use Share → Add to Home Screen. An install button appears only when the browser offers it. HTTPS is required outside localhost.

Installing the shell does not install pretrained weights. Each session still requires you to choose the local ONNX files. Offline operation also depends on browser cache/storage retention.

Experimental on-device text generation for Android and iPhone browsers. The model runs on your phone using WebAssembly, not a remote inference server.
